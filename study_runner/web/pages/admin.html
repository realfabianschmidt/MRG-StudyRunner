Setup Guide
1
Integration erstellen

In Notion unter notion.so/profile/integrations eine interne Integration mit Read, Update und Insert Content erstellen.

2
API Key speichern

Den Token in das API-Key-Feld eintragen. Der Browser bekommt gespeicherte Keys nie zurueck.

3
Page teilen

Eine Notion-Seite fuer StudyRunner Data anlegen und die Integration mit Full Access einladen.

4
Parent Page ID setzen

Die 32 Zeichen aus der Notion-Seiten-URL in den Active Study Target Settings eintragen.
