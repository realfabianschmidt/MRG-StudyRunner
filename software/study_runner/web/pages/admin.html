Upload Integration

Nextcloud Settings

After a study, the result folder is copied to a shared Nextcloud folder. You only need a share link that allows uploading.

Setup Guide
1
Share a folder in Nextcloud

Create a folder for study data, share it as a link, and allow uploading (permission "Allow upload and editing").

-
2
Paste the share link

Copy the link from Nextcloud into the field below. It looks like https://cloud.example.com/s/AbCdEf123.

-
3
Add the password if the link has one

Only needed if you protected the share with a password. It stays on this computer and is never sent back to the browser.

-
4
Test and switch on

Press "Test connection", then switch on the upload for this study and save.

Tablet connection

Certificate

The tablet needs this certificate once so its camera may be used. Scan the code below on the tablet, then follow the steps.

Set up a tablet
1
Scan the code on the tablet

Open the camera app on the tablet and scan the code in the "Tablet setup" card. The download starts by itself.

-
2
Install the downloaded profile

On the iPad: Settings, then "Profile downloaded" at the top, then Install. The iPad asks for its passcode.

-
3
Switch on full trust

Settings, General, About, Certificate Trust Settings: switch on "Study Runner Local Root CA". Apple requires this last step to be done by hand.

-
4
Open the study page

Use the participant link from the hub. The page should open without a warning and may use the camera.
