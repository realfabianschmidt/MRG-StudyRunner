Setup Guide
1
Create an integration

In Notion, under notion.so/profile/integrations, create an internal integration with Read, Update and Insert Content.

2
Save the API key

Paste the token into the API key field. The browser never receives saved keys back.

3
Share the page

Create a Notion page for StudyRunner data and invite the integration with full access.

4
Set the Parent Page ID

Enter the 32 characters from the Notion page URL into the Active Study Target settings.
